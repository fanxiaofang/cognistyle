

> **把“社交叙事系统”从文案系统，升级成“语义分层系统”**

解决四层之间存在“语义越权”。

下面是一套**完全对齐、不会漂移的统一架构（v6语义模型）**。

# 🧭 v6.0 统一语义链路（无漂移版本）

## 总原则（非常关键）

整条链路必须遵守一个约束：

> **每一层只回答一个问题，不允许跨层解释**

---

# 🧱 四层职责重新定义

## ① pattern（结构分类层）

### ❗只做一件事：

> **描述“关系结构类型”**

不解释原因、不讲故事、不讲好坏。

---

### ✔ 标准定义

| pattern       | 定义       |
| ------------- | -------- |
| homogeneous   | 多维高度一致   |
| complementary | 互补维度占主导  |
| asymmetric    | 互补与错位并存  |
| conflicting   | 高冲突维度占主导 |

---

### ❌ 禁止行为

* 不讲“你们适不适合”
* 不讲“协作体验”
* 不讲“像什么关系”

---

# 🏷️ ② badge（视觉标签层）

### ❗只做一件事：

> **把 pattern 翻译成用户可感知的“意象标签”**

---

### ✔ 标准结构

| pattern       | badge    |
| ------------- | -------- |
| homogeneous   | 🪞 回声组   |
| complementary | 🧩 经纬组   |
| asymmetric    | ⚙️ 双星共轨组 |
| conflicting   | ⚡ 化学反应组  |

---

### ✔ badge规则

* 只做“命名 + 意象”
* 不解释
* 不描述关系

---

### ❌ 禁止

* ❌ “默契天成”
* ❌ “互补协作”
* ❌ “容易冲突”

👉 这些全部属于 summary

---

# 🧾 ③ summary（关系叙事层）

## ❗这是最关键一层

> **解释“你们作为一对搭档会发生什么”**

---

### ✔ summary必须回答：

> “这种组合在现实协作中会怎样运作？”

---

### ✔ v6统一定义

| pattern       | summary核心          |
| ------------- | ------------------ |
| homogeneous   | 高一致 → 快速对齐         |
| complementary | 互补结构 → 分工协作        |
| asymmetric    | 局部互补 + 局部错位 → 需要协调 |
| conflicting   | 高冲突 → 需要规则         |

---

### ✔ 修正版 summary（最终稳定版）

## 🪞 homogeneous

```text
你们在大多数问题上会自然达成一致，沟通成本很低，协作推进速度快。在需要不同视角的任务中，可以引入外部输入来补充判断。
```

---

## 🧩 complementary（关键修正）

```text
你们在不同认知维度上形成互补，一个更擅长打开局面，一个更擅长收敛和补全。只要分工清晰，协作效率会很高。
```

---

## ⚙️ asymmetric（核心修正）

```text
你们在部分维度上配合顺畅，但在另一些维度上存在明显差异。这种组合既有互补空间，也需要通过明确分工减少错位成本。
```

---

## ⚡ conflicting

```text
你们在多个关键维度上存在明显分歧，协作中容易出现拉扯。但如果提前设定规则和决策方式，这种差异也可以转化为更高质量的结果。
```

---

# 📊 ④ dimensionInterpretation（维度解释层）

## ❗只做一件事：

> **解释“这个分数在该维度上代表什么”**

---

### ✔ 不允许：

* 不讲 pattern
* 不讲关系
* 不讲结果

---

### ✔ 标准结构（强制统一）

必须是：

> “这个维度 = 什么能力 / 行为倾向”

---

### ✔ v6统一版本

## 🧠 认知互补

```text
双方在看待问题与解决问题方式上的互补程度
```

---

## 🔍 盲区覆盖

```text
双方在认知盲点上的互相补足程度
```

---

## ⚡ 节奏协同

```text
双方在决策与执行节奏上的匹配程度
```

---

## ⚙️ 摩擦风险

```text
双方差异在协作中可能带来的阻力程度
```

---
